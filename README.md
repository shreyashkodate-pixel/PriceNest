# PriceNest 🏠

> **Residential Real-Estate Price Prediction Engine for Pune, Maharashtra, India**

[![CI](https://github.com/shreyashkodate-pixel/PriceNest/actions/workflows/ci.yml/badge.svg)](https://github.com/shreyashkodate-pixel/PriceNest/actions)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Status: Phase 1](https://img.shields.io/badge/Status-Phase%201%3A%20Foundation%20%26%20Docs-green.svg)](#current-status--roadmap)

PriceNest is a full-stack, data-driven residential real-estate price estimation platform. Its initial focus is the fast-growing real-estate market of **Pune, Maharashtra, India**, spanning prime tech corridors (Hinjawadi, Kharadi, Magarpatta), established urban zones (Kothrud, Baner, Viman Nagar), and expanding PCMC/PMRDA suburbs (Wakad, Ravet, Punawale).

The application provides instant, transparent property valuations in Indian Rupees (INR Lakhs and Crores), computes per-square-foot benchmarks, supports authenticated user accounts with private prediction history, and presents model explanations and disclaimers.

## ⚠️ Important Notice on Initial Development Dataset

The initial machine learning model is trained on a **Kaggle development dataset** for experimental and educational prototyping:
- **Synthetic & Heuristic Nature:** This dataset contains synthetic or heuristically scraped observations.
- **Unverified Records:** It **does NOT represent verified government deed registrations, official Ready Reckoner (RR) rates, or authenticated Index-II property records from the Maharashtra Department of Registration and Stamps.**
- **No Financial/Legal Reliance:** Outputs generated by this development model are illustrative algorithmic simulations and must never be used as statutory appraisals, certified valuations, or definitive purchase advice.
